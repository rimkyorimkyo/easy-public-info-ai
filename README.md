# AI 기반 공공 안내문 쉬운 글 변환기

프로그램 링크: exs-dc253unf3r2c73ebot10 

복잡한 공공 안내문을 이해하기 쉬운 글로 바꾸고, 원문과 변환문을 나란히 비교하는 웹 프로그램입니다. 서버와 화면을 만들기 위해 필요한 외부 패키지는 사용하지 않습니다.

## 1. 프로젝트 목적

- 복지, 교육, 행정, 고용, 건강 안내문을 쉽게 이해할 수 있도록 돕습니다.
- 원문과 변환문의 글자 수, 문장 수, 평균 문장 길이, 어려운 표현 비율을 비교합니다.
- 날짜, 숫자, 전화번호, 기관명 등 주요 정보를 원문과 대조하여 확인합니다.

## 2. 주요 기능

- 교육용 공공문서 샘플 선택
- 원문 직접 입력 및 수정
- Zhipu AI GLM API를 통한 실제 쉬운 글 변환
- PC에서는 좌우 비교, 모바일에서는 위아래 비교
- 변환문 복사 및 UTF-8 텍스트 다운로드
- 글자 크기 조절과 전체 초기화
- 키보드 조작과 스크린리더를 고려한 화면 구성

## 3. 실행 환경

- Python 3.10 이상 권장
- 별도 프론트엔드 빌드 도구가 필요하지 않습니다.
- 설치가 필요한 외부 Python 패키지가 없습니다.

```bash
python3 server.py
```

브라우저에서 `http://localhost:8001`을 엽니다.

## 4. GitHub Codespaces에서 실행

1. 터미널에서 `python3 server.py`를 실행합니다.
2. VS Code 아래쪽의 **Ports** 또는 자동으로 표시되는 포트 메뉴를 엽니다.
3. 포트 `8001`을 선택합니다. Codespaces에서는 포트가 자동으로 전달되고 브라우저가 열립니다.
4. 브라우저로 열기 아이콘을 눌러 웹사이트를 확인합니다.

Codespaces 주소는 해당 Codespace가 실행 중일 때 사용하는 개발용 주소입니다. Codespace를 중지하거나 포트 공개 권한이 바뀌면 주소가 열리지 않을 수 있으며, 다른 사람이 접근하려면 포트 공개 범위를 별도로 바꿔야 합니다. 계속 사용할 공개 링크는 아래 방법으로 배포하세요.

## 공개 링크 배포 (Render)

저장소에는 Render 배포 설정인 `render.yaml`이 포함되어 있습니다. 배포하면 `https://<서비스이름>.onrender.com` 형태의 주소가 생기며, Codespaces를 종료해도 다른 사람이 접속할 수 있습니다.

1. 저장소를 GitHub에 푸시합니다.
2. [Render](https://render.com/)에서 **New > Blueprint**를 선택하고 이 GitHub 저장소를 연결합니다.
3. Blueprint가 `render.yaml`의 서비스를 찾으면 배포를 진행합니다. 설정 요청 시 Zhipu AI의 `GLM_API_KEY`를 입력합니다.
4. 배포 완료 후 Render 대시보드에 표시되는 `onrender.com` 주소를 공유합니다.

`GLM_API_KEY`는 Render 환경변수로만 설정하세요. 저장소나 브라우저 코드에 넣으면 안 됩니다. 무료 서비스는 일정 시간 사용하지 않으면 잠들 수 있어 첫 접속에 시간이 걸릴 수 있습니다. 공개된 변환 기능은 설정한 GLM 계정의 API 사용량과 요금에 반영되므로, API 계정의 사용량 한도와 청구 내역을 확인하세요.

## 5. GLM API 키 설정

`.env.example`을 복사하여 `.env`를 만듭니다.

```bash
cp .env.example .env
```

`.env` 파일에 다음 값을 설정합니다.

```text
GLM_API_KEY=실제_API_키
GLM_API_BASE=https://open.bigmodel.cn/api/paas/v4/chat/completions
GLM_MODEL=사용할_GLM_모델명
PORT=8001
```

Codespaces에서는 Secrets에 `GLM_API_KEY`를 등록하고 서버를 새로 시작하는 방법도 사용할 수 있습니다. API 키는 프론트엔드나 저장소에 넣으면 안 됩니다. `.env`는 `.gitignore`에 포함되어 Git에 올라가지 않습니다.

API 키가 없으면 웹 화면은 API 키 미설정 상태를 표시하고 변환을 차단합니다. 가짜 변환 결과를 만들지 않습니다.

## 6. 파일 구조

- `server.py`: 웹 페이지와 `/api/status`, `/api/samples`, `/api/convert` 제공
- `glm_client.py`: GLM API 요청과 응답 검증
- `analyzer.py`: 문장 및 주요 정보 분석
- `index.html`: 메인 화면
- `css/style.css`: 화면 디자인과 반응형 레이아웃
- `js/app.js`: 샘플 선택, 변환 요청, 그래프와 복사 기능
- `data/terms.csv`: 어려운 행정 표현 참고 데이터
- `data/research_samples.csv`: 교육용 재구성 예시 자료
- `.env.example`: 환경변수 설정 예시
- `render.yaml`: Render 공개 배포 설정

## 7. 주요 기능 테스트

1. 서버를 실행하고 메인 화면이 열리는지 확인합니다.
2. 샘플을 선택하면 원문 입력창에 내용이 들어오는지 확인합니다.
3. API 키 없이 변환을 누르면 설정 안내가 나오는지 확인합니다.
4. API 키를 설정한 뒤 변환을 누르고 원문과 변환문이 나란히 표시되는지 확인합니다.
5. 복사와 TXT 다운로드가 동작하는지 확인합니다.

Python 분석 함수를 직접 확인할 수도 있습니다.

```bash
python3 -m unittest discover -s . -p "test_*.py"
python3 -m json.tool < /dev/null
```

실제 GLM API 키와 네트워크가 준비되지 않은 경우에는 실제 변환 성공을 확인했다고 보고할 수 없습니다.

## 8. 분석 기준

- 글자 수: 공백을 포함한 전체 문자 수
- 공백 제외 글자 수: 모든 공백을 제외한 문자 수
- 문장 수: 마침표, 느낌표, 물음표, 줄바꿈을 기준으로 계산한 문장 수
- 평균 문장 길이: 공백을 제외한 글자 수를 문장 수로 나눈 값
- 어려운 표현 비율: 등록된 어려운 표현이 전체 단어에서 차지하는 비중

어려운 표현 비율은 참고용이며 모든 문장의 실제 난이도를 정확하게 측정하지 않습니다.

## 9. 주요 정보 검증과 한계

원문과 변환문을 비교하여 날짜, 숫자, 전화번호, 기관명, 신청 대상, 자격 조건, 제출 서류, 신청 방법, 장소를 확인합니다.

이 검사는 단순한 문자열과 패턴 비교 방식입니다. 발견되지 않은 항목은 누락이 확정되지 않았으며 사람의 확인이 필요합니다. 쉼표나 띄어쓰기는 일부 정리하지만, 완전한 의미 이해나 수치의 의미까지 확인하지는 못합니다. 신청 전에 공식 기관의 최신 안내를 확인해야 합니다.

## 10. API 오류 해결

- API 키 미설정: `.env` 또는 서버 환경변수에 `GLM_API_KEY`를 설정합니다.
- 인증 실패: 키가 올바른지 Zhipu AI 설정 화면에서 확인합니다.
- 요청 한도 초과: 잠시 후 다시 시도합니다.
- 서버 일시 오류: 잠시 후 다시 시도하거나 GLM 서버 상태를 확인합니다.
- 연결 실패: `GLM_API_BASE` 주소와 인터넷 연결을 확인합니다.
- 빈 응답 또는 응답 형식 오류: 모델명과 API 응답을 확인하고 다시 시도합니다.
